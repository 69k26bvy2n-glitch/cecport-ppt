# 页型打法与技术手册

每种页型给“结构 + 关键参数 + 坑”。坐标单位 in，画布 13.333×7.5。所有页统一 new_page/header/footer。

## 0. 通用做法

- 一页一个 build 段落函数或顺序脚本；先 `card()` 铺容器再放内容。
- 先定网格常量（BX/BY/BW/BH、列宽、行高），所有元素从常量推导，不写魔法坐标。
- 每页内容装不下时：先提层级（归纳小标题），再缩字号（不破 9pt 下限），再考虑拆页（需用户同意，文案不丢）。

## 1. 封面

- **首选 `cover-clean.jpg` 通栏铺满**（16:9 正好 3200×1800 不裁切），标题排在**左侧留白区**（x≈0.95 起、y≈2.0 起，宽度控制在 5.6in 内，避开右侧弧线与左上 logo）。**封面主标题 40–48pt（2026-10-18 用户定稿：42pt）Bold NAVY，且不放任何标题装饰**（竖条/方块/下划线都不要）；封底同理不放装饰，主标题 36pt 左右。
- 信息行（汇报人 / 周期 / 总量口径）一行 11pt，底部一行 8.5pt MUTE 记录口径；**不要**再叠加白卡盖住背景。
- 不注入页脚通栏；封底用同一张 `cover-clean.jpg` 做书档呼应，右侧或左侧放"感谢聆听 / THANKS"与署名。
- 旧做法（`cover-bg.jpeg` + 左下白卡承载信息）仅在需要官方原版封面时沿用——该图烤死了英文主标题与合作伙伴 logo，白卡会切到弧线。

## 2. 章节过渡页

- 居中：章节序号（大号 MIST/描边）+ 章节名 30–34pt NAVY + 一句英文 kicker；可配一枚 0.9in 浅蓝 icon_chip。
- 无页脚；底部留空，节奏与内页拉开。

## 3. 长文介绍页（字多）

- 顶部一句话主张（16pt Bold NAVY，可前缀橙竖条）；正文拆 3–5 个事实块，每块 = 小图标/方块 + 小标题 + 1–2 行描述。
- 关键数字单独做 KPI 卡：TINT_OR 底（核心）或 TINT 底，大数字 28–34pt + 12pt 单位 + 名称。
- 禁止整段 9pt 灰字铺满；行距 1.25–1.4。

## 4. 卡片矩阵 / 方案菜单（如“七方案”“选配菜单”）

- 等分网格：cw=(总宽-(n-1)gap)/n，gap 0.15–0.20；卡高按内容统一。
- 卡头：序号格（1–n，蓝阶轮换、相邻不同蓝，末位或推荐项用橙）或 icon_chip；标题 12–13pt Bold NAVY；描述 9.5–10pt SUB。
- 同级卡片视觉重量一致；推荐/主推卡用橙头或 TINT_OR 底单独强调。

## 5. 图文页（左图右文 / 上图下文，如 VMI、单方案页）

- 图占 40–46% 宽装白卡（烤色位图样机：先 PIL 统一 2x 居中裁切+圆角 0.06 再入卡）；右侧事实点列表，每点 chip（数字/对勾）+ 粗小标题 + 描述。
- 底部价值带：TINT2 圆角条 h0.44，内文 10.5pt Bold BLUE 居中。
- 烤在原图里的旧配色改不了 → 原图装卡，列入交付清单。

## 6. 数据图表（主打：形状信息图）

**默认全部用形状手摆，不用原生 chart**（直角条、极小值过细、风格不统一）。

横向条形/排名图几何（五仓实测定稿）：

- 卡内绘图：首行中心 TY=卡顶+1.62，行距 PITCH=0.60，条高 0.40，药丸 radius=0.5。
- 标签框 x=卡左+0.30，宽=X0-卡左-0.42，右对齐 10.5pt Bold NAVY；柱基线 X0=卡左+1.92；条右界=卡右-0.28，再留 0.78 给外端数字。
- 条宽 `max(绘图宽*v/vmax, 0.10)`；第一名 ORANGE + 同色柔光（soft_shadow blur0.12/dist0.04/alpha20/color E86F0B）+ 条左端 0.14 处白色 medal 0.25in；2–5 名 NAVY/BLUE/SKY/MIST。
- 数字：第一名 12.5pt 白条内右端；其余条宽≥0.95 白字条内右端 11pt；不足 0.95 外端 INK 11pt。
- 0/2/4/6 竖网格 GRID #EDF1F6 0.5pt + 8pt MUTE 刻度；注释行写明“极小值短宽保底，以数字为准”。
- 卡右上角地图线稿水印 alpha 6%。
- 同卡可配“贸易方式”标签行：TINT 底 BLUE 字 / TINT_OR 底 ORANGE2 字 tag。

其他图型类推：占比用水平堆叠条或环形（环形用 OVAL + 弧/饼段，数字端注）；对比用成对药丸；不要做 3D、不要阴影网格面。

### 四象限矩阵（双维度分层定位，2026-10-16 新增，实测已过 QA）

⚠️ **2026-10-16 用户返工定稿：必须画真坐标轴，不能只把轴名写在图上下面。** 旧版把「业务增长潜力↑」放在卡上方、「年度采购规模→」放在卡下方，用户原话"左边这个应该是个数轴图吧……但是你这个并没有很好地表现出来"——象限矩阵是定位图，读图靠轴。定稿做法：

- 卡 MX0.55/MY1.70/MW8.60/MH4.56。**绘图区边界（2026-10-16 用户返工定稿）**：`AXX=MX+0.50`、`PX1=MX+MW-0.50`（卡内**左右各 0.50in 等距**，旧版 0.68/0.30 严重不对称被指"左右视觉没对齐"）；`PY0=MY+0.46`、`AXY=MY+MH-0.66`（**上下视觉等距**，底边距必须留够 0.42in 给 X 刻度＋轴标题，旧版 0.34/0.78 上紧下松被指"上下没有"）；Y 轴竖排标题 `cx=MX+0.25=0.80` 居中于左侧沟槽。
- **轴与色块必须留缝**（用户"坐标被色块遮住一半"）：轴 1.5pt 线居中在 AXX/AXY，色块若与轴共边会压掉靠内半根线。定 `GAP=0.10in`，色块四边统一内缩：`FQ0=AXX+GAP, FQ1=PX1-GAP, FY0=PY0+GAP, FY1=AXY-GAP`；`qw=(FQ1-FQ0)/2=3.70`、`qh=(FY1-FY0)/2=1.62`，象限原点 `qx=FQ0+ax_*qw, qy=FY0+ay_*qh`；分界虚线只跨色块，不压轴。
- **两根轴都是带箭头的实线**：X 轴 `add_line_xy(AXX,AXY,PX1,AXY,SUB,1.5)+set_arrow(tail=True)`（**箭头必须用 tail**，headEnd 画的是起点）；Y 轴 `add_line_xy(AXX,AXY,AXX,PY0-0.22,SUB,1.5)+set_arrow(tail=True)` 向上。
- **象限分界**：内部分界用 `MIST` 0.75pt 虚线（`set_dash(l,"dash")`）中轴十字，**不是白色净空线**（白色净空在浅底象限上会被读成"没界线"，且与真轴线语言冲突）。
- **刻度**：两轴各写「低/高」9.5pt MUTE——Y 轴在 `AXX-0.58` 右对齐、分别位于绘图区顶/底；X 轴在轴下方两端。
- **轴标题**：Y 轴用**原生 eaVert 竖排**（`vtxt()`：`add_text` 后在 `a:bodyPr` 写 `vert="eaVert"` 且四个 ins 清零，**绝不旋转文本框**），置于 `MX+0.26` 绘图区中线，12.5pt Bold BLUE；X 轴标题 10.5pt Bold BLUE 居中于轴下方。
- **象限底色轮换**（TINT2/TINT_OR/TINT/TINT2）accent SKY/ORANGE/SUB/BLUE；**战略象限单独 TINT_OR+ORANGE**（全页唯一暖色象限）。象限用 **RECTANGLE 平铺直角**。
- 每象限纵向节奏（相对 qx,qy）：名称 14pt Bold accent @+0.10 → 统计 11pt Bold accent @+0.44 → 0.12in 占比条 @+0.80（HAIR track + accent fill，`(qw-0.36)*pct/100`）→ 策略 10pt SUB line_spacing1.2 @+0.96。
- **象限大号浅色水印图标**（用户"四块里面文字比较少，叠加一个浅色、大的那个图标"；2026-10-16 修正定稿）：**按象限色系重染成浅色剪影、不叠透明度**（`wm_icon()` 直接贴图；色值 潜力 SKY 系 `#C7E0FA`／战略 ORANGE 系 `#F8D4B6`／基础 SUB 系 `#C9D5E2`／重点 BLUE 系 `#B8D6F6`），0.76in 放 `qx+qw-0.90, qy+0.03`（**唯一无内容区 = 统计文字右侧、占比条上方的右上角**），图标取该象限语义（chart/medal/coins/target）。**旧版"统一 NAVY 图标 + `pic_alpha(8%)` + 1.30in 放右下角"已废止**——渲染呈灰蓝与橙色象限不搭，且必然压占比条与策略文字行（`a:alphaModFix amt` 也已在 `pic_alpha` 里不用）。
- 右侧结论栏同高独立白卡（RX9.62/RY1.70/RW3.16/RH4.56）：`card_title(marker=ORANGE)` + n 条结论。**徽号与文字必须共用同一中心线**（用户点名"数字和文字、序数字序号和文字没有对齐，应该要检查出来"）：`by = ry+(rh-0.34)/2` 的 0.34in 圆，文字框 `RX+0.72, w=RW-0.96` 且 `anchor=MIDDLE`。**条目行距与位置（2026-10-16 用户两轮反馈定稿）**：`rh=0.66, gap=0.06`（行距 **0.72**；旧 `rh0.86/gap0.10` 行距 0.96 被指"4 点内容间隔有点宽"）；`ry0 = RY+0.78` **紧凑顶排贴标题**（曾按上下等距居中，用户否："离标题太远了"）；底部空余用大号浅色图标补（`wm_icon(s,"chart", RX+RW-0.20-0.86, RY+RH-0.16-0.86, 0.86, (0xD6,0xE4,0xF3))`，规则见 design-spec §5.1）。多 run 混排：数字 NAVY Bold、末条关键值 ORANGE。

### 对比矩阵表（n 维度 × m 方案，2026-10-16 新增，实测已过 QA）

- 整表装一张白卡（BX0.55/BY1.34/BW12.23/BH4.86）；表宽 `tW = dcw + m*scw`，`scw=(BW-0.40-dcw)/m`（维度列 **dcw=2.05**，给图标留位）。
- 表头 `hy=BY+0.18, hh=0.56`：维度列表头 TINT2+NAVY 11.5pt；各方案列头**实心色块**（NAVY/BLUE/ORANGE）+ 白字 12.5pt 居中。
- **维度列必须配图标**（2026-10-16 用户："服务模式对比这里没有什么东西"——整页纯文字显空）：每个维度名左侧 0.22in Tabler 图标（`x0+0.14, ry+rh/2-0.11`）+ 名称 11pt Bold NAVY（`x0+0.44, w=dcw-0.58`）。图标按维度语义选：适用客户 target／核心交付 truck／账期 coins／最低起订 package／库存责任 warehouse／技术支持 gear／典型场景 chart。
- 数据行 `ry0=hy+hh, rh=0.531`：维度列 TINT；值列 `CARD / TINT2` 隔行换色 + SUB 10pt，全部 MIDDLE 对齐、左右 padding 0.16。
- 分隔线：横 6 条 + 竖（各方案列左缘）用 HAIR 0.75pt——**所有单元格用 RECTANGLE 平铺手摆，不用原生 table**（原生表格套不上色板与发丝线语言）。
- 表内注 8.5pt MUTE 放卡内底部（y5.88，起点 x0）；来源署名（如"市场部 2026.3 整理"）放卡外左下 6.32。

### 备选：python-pptx 原生真 chart（客户明确要双击改数据时）

库版本 python-pptx 1.0.2 踩坑结论：

- Chart 无 chart_area 属性；CT_ChartSpace/CT_PlotArea 无 spPr 助手 → `makeelement` 手工插 `c:spPr`（a:noFill + a:ln/a:noFill），schema 顺序：chartSpace 的 spPr 在 c:txPr 前；plotArea 的 spPr 在 c:barChart 前。
- `c:txPr` 必须完整：a:bodyPr + a:lstStyle + a:p/a:pPr/a:defRPr；defRPr 上写 sz/b + solidFill + latin/ea/cs（MiSans），**solidFill 必须在 latin 之前**。
- 单系列必须设 `<c:autoTitleDeleted val="1"/>` 并插在 c:chart 首位，否则系列名变自动标题。
- 数据标签：`dl.show_value=True`（默认 False 不显示！）、number_format 如 `'0.0"万㎡"'`、number_format_is_linked=False、position=OUTSIDE_END。
- category_axis.reverse_order=True 首类在上；value_axis.visible=False；逐点着色 `ser.points[i].format.fill.solid()`；gap_width≈40–55。
- 辅助函数 `_ea_on_defRPr / set_tx_font / _no_fill_spPr` 在历史工程 build 脚本里，重写时照本节要点实现。

## 7. 地图页（仓网/网点分布）

- 原图轮廓：PIL 裁掉自带标题、保留审图号，整体入卡。
- 点位全部原生重绘：OVAL + 白边 + 引导细线 + 胶囊标签；中心/主仓 ORANGE，其余蓝阶；密集点群（如珠三角）标签排到地图下方一行扇形引线，禁止标签互相压。
- 侧栏数据行：大数字（橙=主，其余蓝）+ 名称 + 保税/完税 tag + 原文描述 + 按比例数据条（极小值 min 0.20in）。

## 8. 流程页

### 8.1 燕尾 CHEVRON（环节少、横向 4–7 段，如仓配关运）

- MSO_SHAPE.CHEVRON，adjustments≈0.22；step 略小于 w 使箭头咬合；蓝阶递进、末段 ORANGE。
- 白图标 + 11–12pt 白字居中；下方挂每段 1–2 条明细。

### 8.2 时间轴（环节 4、上下交错，如全链路服务模式）

已验证几何（卡 BX0.55/BY1.55/BW12.23/BH5.27）：

- 主轴 AXY=BY+2.50，起点 AX1=BX+1.80，终点 AX2=BX+BW-2.33；主轴 MIST 高 0.07 + 右端 CHEVRON(adjust0.55)。
- 两端盒：h0.84 y=AXY-0.42；起端 ORANGE（如 x=BX+0.35 w1.28），终端 NAVY（x=BX+BW-1.75 w1.45），白字 13.5pt。
- 4 站点四等分，NODE_D=0.58，上下交错 DY=1.55：蓝阶圆 + 白 PNG 图标 0.37in + 2pt 竖连线 + 轴上 0.15 小圆点；标题 13pt NAVY，三条明细 9.5pt SUB（上站明细框 cy+0.13/AXY-1.00 宽1.50；下站 AXY+0.16）。
- 底部价值带 y=BY+BH-0.62 h0.44 TINT2，10.5pt Bold BLUE 居中。
- 站点上下交错后几何必须实际渲染确认不压价值带。

### 8.3 泳道流程图（多角色 + 信息流/物流双层，如 VMI）

跨三个角色列（供应商→平台 HUB→客户基地）+ 顶部客户盒的复杂流程，2026-10-15 定稿打法。完整可跑样例：`examples/p11_vmi_swimlane/build_p11.py`（组件均在 cec_lib，改坐标常量即可复用）。

**骨架与配色**

- 角色列：`dashed_box()` TINT2 底 + SKY 1.1pt 虚线圆角容器（圆角走 R_CARD 档）；标题 `lane_title()` 实底药丸（两端 NAVY、平台主角 ORANGE），卡内元素**无阴影**。
- 两类流严格分语言：**信息流 = BLUE 1.25pt 虚线 + 小三角**；**物流/作业流 = ORANGE 2.25pt 实线 + 三角**（`set_dash()` / `set_arrow()`）。卡标题行放迷你图例"信息流 ┄ / 物流 →"。
- 列间隙留 0.62in 放竖排流向标签。折线用两段 connector 拼（水平段无箭头、垂直段末端 tail 箭头）；斜向虚线用于跨角色订单流。
- 角色容器内记录行用白卡 HAIR 边、圆角 R_BOX；多对一来源配左侧区域标签列（TINT/BLUE，"境内区外"类标签可纵跨两行）。
- 平台列 3×3 服务网格用 icon_chip + 8.8pt 短称；原文服务全称（"报关、物流、……不良品退换"）一字不动放底部 TINT_OR 盒，短称与全称互为索引不算改义。

**穿线标签规则（全页所有标签统一语言，用户定稿）**

1. **横排标签坐线上 → `line_pill(cx, cy, w, 文字, 字号)`**：白色圆角胶囊 + **与线同色 1pt 描边** + 字色随线；胶囊压住连线断线。水平线标签胶囊宽按文字定（4 字 0.69 / 6 字 0.96，高 0.20）。
2. **斜线上的标签整条沿走向旋转**：`line_pill(..., rot=degrees(atan2(dy,dx)))`（P11 斜线 ≈14.2°），胶囊与文字框同角、绕共同中心；旋转后线从短边穿出，两段端点 = 中心 ± (w/2−0.02)·单位射线向量。
3. **间隙放不下横排 → `vlabel(cx, cy, 文字, color=线色)`**：原生 `eaVert` 竖排（**绝不旋转文本框**——旋转是横排字形硬转且方向易错）；文字框本身**白色实填、直角、无描边**（VL_W=0.22，高=字数×字号/72×1.22，wrap=False，bodyPr 四个 ins 必须清零否则竖列顶偏 0.1in），居中压贯通线断线，字色随线。
4. **连线断口**：实线可整条贯通由白框/胶囊压线；**虚线必须画两段**，端点切入框内 0.02in（整条贯通时虚线周期性会在白框边外露碎头）。
5. **箭头方向**：`a:headEnd` 装饰画线**起点**、`a:tailEnd` 才在画线终点（沿 add_line_xy 的 (x1,y1)→(x2,y2) 方向）。双向流两端外张 head+tail（两段各在泳道边画 tail 反向）；单向流只在目的端 tail，源侧线段无箭头。
6. **放不下的例外**：短竖桩（如客户盒与 HUB 标题间 0.28–0.30in）塞不进任何标签框时，退回箭头侧 7.5pt 横排小字，不套底框、不压线。

**阴影与圆角（本页型照此执行，通条见 design-spec §6）**

- 圆角按绝对英寸三档统一，`rr(w,h,r)=r/min(w,h)` 换算（adjustments[0] 是短边比例不是英寸！）：外卡/客户盒/泳道容器 R_CARD=0.10；记录白卡/区域标签/全文盒 R_BOX=0.08；图标方块 0.12（chip 0.44 见方用比例 0.28）。
- 阴影只给三张外层卡片：`card_shadow()`（blur0.09/dist0.022/alpha9）；药丸、客户盒等卡内元素一律无投影。

### 8.4 复杂网状关系图

手摆成本高时仍优先拆成“分层 + 主轴”表达；不引入 Mermaid 自动转换（默认黑框、需全套二次整形，已评估放弃）。

### 8.5 组织架构树（1 + n 中心 + 部门列，2026-10-16 新增，实测已过 QA）

- **L0 主干盒**：居中 `add_rect(CX-1.40, 1.30, 2.80, 0.60, fill=NAVY, radius=rr(2.80,0.60,R_CARD))` + 白字 14.5pt Bold CENTER。

## 11. 图标扩展

assets/icons2 现有：target medal gear globe coins bolt shield chart warehouse pick customs truck mappin map digital database package，以及 2026-10-16 新增的 cpu / usb / mouse（芯片、USB 接口、鼠标，均为 qlmanage 流程产出）。

需要新图标时（Tabler，MIT）：

1. 下载 SVG：`https://cdn.jsdelivr.net/npm/@tabler/icons@3/icons/outline/<name>.svg`（raw.githubusercontent 会超时）。
2. 把 `stroke="currentColor"` 染成 `#0057C8`（深蓝版）；需要白版则涂白。
3. Node + @resvg/resvg-js 渲染 512px PNG，透明底，分别存 icons2/ 与 icons2w/。
4. 也可直接用已有 PNG 经 PIL 保 alpha 换色（RGBA 逐像素只改 RGB 不改 A）。
5. **无 Node/resvg 时的兜底（2026-10-16 实测可用）**：本机没装 @resvg/resvg-js 且 cairosvg/svglib/rsvg-convert 都没有，只有 `/usr/bin/qlmanage`。做法是把 SVG 的 `width/height` 从 24 改成 512（保留 `viewBox="0 0 24 24"`），再 `qlmanage -t -s 512 -o outdir x.svg`——**注意它会把透明底压成不透明白底**，必须事后用 PIL 把白转 alpha：对每个像素 `cov=(255-R)/255`（线条纯蓝 R=0，白底 R=255），据此重建 `(0,87,200, cov*255)` 的单色抗锯齿 RGBA。不缩放 SVG（只靠 `-s`）会得到左上角极小的图标。
6. ⚠️ **已修 typo 资产**：`icons2/coins.png` 原先是错的（下载时映射到了 trending-down 折线，语义与"账期/钱"完全不符），2026-10-16 已用上面的 qlmanage 流程重制为真正的叠放硬币。**扩图标前先肉眼核验每个 PNG 的图形**，文件名对不上是历史遗留问题。

## 12. OOXML 高频手法

- 图片整体透明度：`pic._element.find(".//a:blip")` 下加 `a:alphaModFix amt=百分比*1000`。
- 形状纯色 alpha：cec_lib.fill_alpha(shape, pct)。
- 手写 p:sp 时命名空间必须是 `.../presentationml/2006/main`（漏 /2006/main 形状会被静默丢弃）。
- 跨 deck 搬形状：deepcopy 源 sp/cxnSp，改 a:off/a:ext 后 append 到目标 spTree（无图片关系时可直接搬，PPT 实开无修复）。
- 连接器：add_connector(1, x1,y1,x2,y2)，记得 shadow.inherit=False。

## 13. 层叠能力带（三层/多层能力结构，2026-10-16 新增，实测已过 QA）

适用于「芯 — 板 — 端」这类自下而上讲的能力分层（单页：`思尼克星闪全栈研发能力_中电港风格.pptx`）。

- **骨架**：n 条**全宽白卡横带**纵向堆叠——`card(BX0.55, ry, BW12.23, RH1.66)`，带间距 `GP=0.20`（3 条带 y=1.42 / 3.28 / 5.14，底 6.80，页脚带留净空）。每条带内部**横向三段式**：层色块徽章 + 产品列 + 规格网格，中间一条竖 HAIR 0.75pt 分区线（x=5.90，ry+0.30→ry+1.36）。
- **层色严格递进**：NAVY → BLUE → 末层 ORANGE（与 §8.1 燕尾「蓝阶递进、末段橙」同一语言）。层色只落在**徽章实底、药丸描边/文字/图标、标签文字**上，不铺大面积橙（橙面积仅在末层徽章 1.42×1.30 一处实底）。
- **层徽章**（0.75 起、1.42×1.30、R_BOX 档圆角，无阴影）：三行居中白字——层序号「第一层/第二层/第三层」10pt → 层字「芯/板/端」23pt（阶梯后 26pt）Bold → 层名 10.5pt。
- **产品列**（`PX=2.45 / PWD=3.20 / PH=0.50`）：**等宽描边药丸**（fill TINT2 + 层色 1.25pt 描边 + radius 0.5），左端 0.26in 处层色图标、0.54 处 13pt Bold 层色产品名，`wrap=False`。两枚产品时上下两行（`ry+0.26` / `ry+0.90`，行距 0.14），单枚时垂直居中（`ry+0.58`）——不左对齐到首行，避免第二行空缺。
- **规格网格**（`SX=6.22`）：**2×2 等宽标签**（`TWD=3.02 / TH=0.38 / 列距 0.20 / 行距 0.18`，fill TINT + radius 0.5 + 居中 13pt Bold 层色字）。规格条数不足 4 时保留空网格位，靠等宽网格维持对齐不乱。
- **产品列与规格列共用同一水平中线 `ry+0.83`**（徽章、药丸、标签全部锚在这条线上）——关联项同轴，避免各列各自居中而错位。
- **带间层叠箭头**：两带之间的间隙中央放 0.18×0.13 的 `MSO_SHAPE.ISOSCELES_TRIANGLE` + `rotation=180`（指下），x 与徽章列中线对齐（1.46），色 MIST（不与任何层色冲突，也不与橙抢色）。
- 产品药丸图标用 `icons2/` 原图 **PIL 保 alpha 重染为层色**（缓存到工程 `_tint/<名>_<HEX>.png`），比维护三套彩色图标省事；图标 0.26in、药丸内文字框宽 `PWD-0.72`。
- 页眉标题 26pt、框宽 9.9in（本页标题 18 字 + 全角逗号，实测 6.9in 不折行）。
