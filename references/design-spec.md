# 中电港风格 · 设计规范

2026-10-14 定版。咨询报告信息图风。所有页型都必须落在本规范内。

### 着色铁律

1. 形状/色块**一律纯色实底**；并列同类元素用蓝阶深→浅区分，相邻同功能元素**禁止同蓝**（会同色连成一片）。
2. **同一张图的数据块上，深浅纯色色阶与渐变色块不得混用**；全图统一使用同一种渐变语言时可以用渐变。
3. `set_gradient` 默认只用于蓝→橙跨色相装饰细线（页眉短线、价值卡短线）。
4. 橙色不压暗、不渐变；一页中橙色面积克制（页眉竖条 + 一个主强调块/第一名）。
5. 白/浅蓝/浅橙是仅有的底色；正文区不铺深色底。

## 2. 字体与字号

- 中文与拉丁统一 **MiSans**（cec_lib 的 set_font 自动写 latin/ea/cs 三处）。
- **正文基准 12pt**（2026-10-16 用户全局拍板，下同）：一整页所有档位按同一比例放大，做法是在生成器里定义 `S(pt)` 字号阶梯函数 + 用同名 `R()` 包装 cec_lib.R（`R(text,size,...) → _R(text, S(size), ...)`），页面代码里的字号写法一律保留原值、由阶梯统一换算，避免逐处手改漏改。基准阶梯：8→9，8.5→10，9→10.5，9.5→11，**10→12**，10.5→12.5，11→13，11.5→13.5，12.5→13.5，13.5→15，14→16，14.5→16.5，23→26（页眉标题）；未命中值按 ×1.2。
- 例外：**备注型文字可小于 12pt**——"内部资料 请勿外传"、页注、署名、图例等仍走 8.5–10.5pt（cec_lib 内部辅助函数如 `tag()` 不经过页面自己的 `R` 包装，传原值即可；`card_title()` 内部用自己的 R，故也不会被放大）。
- 页眉标题 23pt（阶梯后 26pt）Bold NAVY；kicker 10.5pt MUTE；卡标题 13–13.5pt Bold NAVY；组标题 12pt；正文 SUB；注释 MUTE；数据大字 Bold。
- 正文放大后**必须用真实字重量宽复核溢出**：`ImageFont.truetype(字体, 200).getlength(s)/200.0*pt/72.0`（切忌用 `int(round(pt))` 取整，13.5/14/14.5 会量出同值）；页眉标题放大后框宽要同步加宽（23→26pt 时 9.9in）以免长标题折行撞 logo。
- 大数字（KPI）可用 28–40pt Bold，单位 12–14pt。
- 中文段落必须开启避头尾：cec_lib.add_text 已内置（pPr 写 `eaLnBrk="1" latinLnBrk="0" hangingPunct="1"`，run 标 `lang="zh-CN" altLang="en-US"`）。
- **绝不往 presentation.xml 注入 `<p:kinsoku>` 字符表**——PowerPoint for Mac 严格校验，打开直接弹“内容有问题需修复”；Keynote/WPS 放过但不能作为依据。
- 自定义 16:9 后删除 sldSz 残留的 `type="screen4x3"`（cec_lib.new_deck 已处理）。

## 3. 画布与骨架

- 画布 13.333 × 7.5 in（16:9），ML=MR=0.55。
- 页眉：**主标题前一根蓝→橙渐变细竖线 0.07×0.72（x=ML+0.02 y0.40，圆头 radius=半宽，`set_gradient(bar, BLUE, ORANGE, angle=90)`），贯穿主标题与副标题两行**（2026-10-18 用户二次定稿：先否掉"竖条+蓝橙渐变横线"，再否掉"竖条+小方块"，最终定单根渐变竖线）。标题 x=ML+0.26 y0.36（23pt，阶梯后 26pt）；kicker x=ML+0.26 y0.885；右上 logo 高 0.40。**封面与封底不放此装饰**（无页眉体系）。
- 页脚：官方 footer.png 通栏，x=0.5595 y=7.1560 w=12.1167 h=0.1631。**任何元素不得进入 y>7.0 的页脚带**；页码 8pt MUTE 位于其右上。
- 背景装饰：左下 TINT 圆 alpha 35%，右下 TINT_OR 圆 alpha 38%（new_page 自带）。
- 卡片：白 + HAIR 0.75pt + `card_shadow()` 轻投影，圆角绝对 0.10in（`rr(w,h,R_CARD)` 换算）；阴影/圆角细则见 §6。
- 常规双卡布局：左卡 0.55,1.40 宽5.85；右卡 6.62,1.40 宽6.16；卡高 5.50。

## 4. 版面铁律：分组与信息分区

**关联项间距必须 < 非关联项间距。** 每条 QA 必查。

### 4.1 横向条形/排名图

- 标签（类目名）右对齐，文字框右缘距数据条基线 **0.10in**；行间留白 0.20in。标签与条成一组。
- **不加序号圆**：序号会逼出第三列，短标签（3 字）到条的空隙会远大于行距，标签与数据脱节。名次由“排序 + 蓝阶 + 第一名橙色奖章”表达。
- 数据条基线必须统一对齐（同一起点 x）。
- 数字标签：长条放条内右端白色（蓝 3/蓝 4 上白字对比不够，放条外端 INK）；短条一律外端。
- 极小值条允许短宽保底（≥0.10in）保证可见，相邻小值不得等长，真实大小以数字标注为准并在注释说明。

### 4.2 多条记录列表（白卡内 3 层以上信息）

必须做视觉分区，手段叠加使用：

- 行间 HAIR 0.012in 分隔线（首行上方不加）；
- 左侧锚条 0.07in **贯穿整行高**（只包名字区的短锚条锚不住三层信息，禁用）；
- 同组信息：名字+关键数字同一文本框同一行（一个全角空格分隔），二级 tag 紧贴其下 0.03–0.06in；
- 行间留白 ≥ 组内行间距的 3 倍。

### 4.3 卡片矩阵

- 卡片间距统一（常用 0.15–0.20in），卡内 padding 一致；卡间用蓝阶轮换但相邻不同蓝。
- 每卡“图标/序号 → 标题 → 描述”纵向成组，组内距 < 卡片间距。
- **卡内内容不得贴边或越界**：内容与外卡边缘的内距左右 ≥0.14in、上下 ≥0.12in（纵向列表按 page-patterns §4.5 用 `rows_y()` 算行高）；装不下就降字号/拆页，**不许靠缩小内距硬塞**。

### 4.4 QA 眯眼检查（每页 30 秒）

1. 眯眼能否一眼数出页面上有几个信息分区？
2. 每个分区内的 2–3 层信息是否成块，还是各自漂浮？
3. 组间距是否明显大于组内间距？标签和它描述的数据有没有分家？
4. 有没有元素压页脚/出卡边/文字重叠？
5. 卡片内容明显少于容器时，有没有 >0.6in 的大留白放着没处理（见 §5.1）？

## 5. 图标与装饰

- 统一 Tabler Icons 线性图标（MIT），不要混用多套图标、不要手画。
- 深蓝版 `assets/icons2/`（NAVY 描边，用于浅底）；白版 `assets/icons2w/`（用于彩色圆/实底）。
- 典型用法：卡标题 0.26in 深蓝图标；icon_chip 浅蓝圆角方底 0.52in；流程节点彩色圆 0.58in 内嵌 0.37in 白图标。
- 角标水印：线稿 PNG 放大到 1.4–1.6in、alpha 6%，放卡片右上角，只作纹理不得干扰文字（XML：a:blip 下加 `a:alphaModFix amt="6000"`）。
- 每页图标 1–4 个为宜；禁止一排等大图标当内容。
- 扩图标方法见 page-patterns §图标扩展。

### 5.1 大留白处理（2026-10-16 用户定稿）

**判据**：内容块之外的空余 >0.6in（或 > 容器高度的 20%）即视为“过大留白”，必须处理，不能放着。

处理顺序（按优先级）：

1. **内容贴近标题 / 顶部紧凑排列**。不要把内容居中或拉开行距去“填满”容器——2026-10-16 实测：把 P2 结论卡 4 条短句做上下等距居中，用户原话“4 条短句我上移了一些，离标题太远了”，**居中方案被否**。正确做法是 `ry0` 贴住标题盒底（顶距约 0.3–0.45in），行距按内容自然取（短列表 0.66+0.06）。
2. **剩余留白用大号浅色图标补足**（用户：“下面空着可以，也可以加个背景中叠加个图标或者别的装饰”）。复用 `wm_icon()` 按本页色系重染的浅色剪影，**不叠透明度**；结论/文字卡用浅蓝 `#D6E4F3`，象限内用该象限色系（见 page-patterns §四象限）。尺寸 0.8–1.0in，贴区域的**右下角**，与内容块成对角，视觉重量够但不抢戏。
3. **其他装饰备选**：与页眉同语言的蓝→橙渐变短线、极淡的几何弧/网格/层叠图形。装饰用色一律取自本页色板，明度必须足够低，只作纹理。

**硬约束**：摆图标前必须先用 `tw()` 量出邻近文字的右缘（横向）与内容底（纵向），据此反推图标左缘/顶缘，**禁止与任何文字重叠**。反面教训：P2 结论卡末条第二行“率不低于99.5%”右缘 11.58in、文字内容底 5.19in → 图标左缘 ≥11.70、顶 ≥5.24（实际取 11.72 / 5.24）。

## 6. 阴影与圆角

### 6.1 阴影分级（层级语言，2026-10-15 定稿）

- **只有最外层卡片带投影**，用 `card_shadow()`（soft_shadow blur0.09 / dist0.022 / alpha9 / 色 1B2A41）——轻柔贴边的微光；旧默认参数 blur0.10/dist0.035/alpha13 在白底上显脏，已停用。
- **卡内一切元素无投影**：标题药丸、客户盒、标签胶囊、记录小卡、图标块一律不投影，靠实色填充和描边分层。整页层级固定三级：页面底 → 外卡（唯一有影）→ 内容。
- 例外：数据条形图第一名可用同色橙柔光 alpha20（见 page-patterns §6）；节点圆按页型需要可带轻影。

### 6.2 圆角按绝对英寸统一（坑）

python-pptx 圆角矩形的 `adjustments[0]` 是**短边比例**（半径/短边），不是英寸——同写 0.10、高度不同的框实际圆角能差一倍。统一用 `rr(w,h,r)=r/min(w,h)` 换算，三档：

| 档 | 半径 | 用在 |
|---|---|---|
| R_CARD | 0.10in | 外层卡片、客户盒、泳道虚线容器 |
| R_BOX | 0.08in | 内层记录白卡、区域标签、TINT_OR 全文盒 |
| 0.12in | — | 图标方块（icon_chip 0.44 见方用比例 0.28、工厂块 0.56 用 0.22） |

- 药丸/胶囊/tags 一律 radius=0.5（全圆端头）；穿线标签胶囊同此（见 page-patterns §8.3）。
- 同页、同层级的圆角必须一致；不出现直角条+圆角卡混搭。
